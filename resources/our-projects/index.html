Project Willow

Next-Generation Superconducting Quantum Processor

Willow introduces 105 superconducting transmons with unprecedented gate fidelities (>99.9%), demonstrating real-time fault-tolerant surface code error correction below the physical threshold. Willow cuts logical error rates in half as code distance increases from 3 to 5 to 7.

AI for Biomolecular Interaction & Structure Prediction
